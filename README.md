# Cloudbrew - Iced Coffee Shop

A modern, animated iced coffee website for Cloudbrew featuring their signature caramel drink.

## About

This is a landing page designed for Cloudbrew, a newly established iced coffee shop. The design emphasizes their core product - the Iced Caramel drink - while showcasing their menu and providing a modern, engaging user experience.

## Key Features

- **Featured Product Showcase**: Highlighted Iced Caramel drink as the star
- **Interactive Flavor Selection**: Users can toggle between caramel, mocha, and vanilla
- **Smooth Animations**: Parallax effect and transitions for enhanced UX
- **Mobile Responsive**: Optimized for all screen sizes
- **Modern Design**: Clean, playful aesthetic with vibrant colors

## Design Philosophy

This site was built using the taste-skill anti-slop frontend methodology, which emphasizes:

1. **Substance over style** - Strong content structure
2. **Real photographs** - Authentic images of coffee and cafe life
3. **Clear typography** - Easy to read headlines and body text
4. **No unnecessary ornaments** - Clean, focused design

## Technical Details

- Built with vanilla HTML/CSS/JS
- No frameworks or libraries
- Optimized for performance
- Fully accessible

## Colors

The design uses a three-color palette:
- **Orange** (#ff8126) - Background for the hero section
- **Sky Blue** (#4DA6E8) - Background for the menu section
- **Lime** (#c5f53d) - Background for the story section
- **Near-Black** (#161615) - Background for stores and footer

## Special Features

- **Parallax cup tilt**: The coffee cup tilts with mouse movement
- **Flavor-based theming**: Each flavor changes the brand name color
- **Animated floating elements**: Adds depth and visual interest
- **Smooth transitions**: Fade effects when swapping drinks
